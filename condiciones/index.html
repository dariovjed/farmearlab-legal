Condiciones de uso

Última actualización: 25 de octubre de 2026 · Versión para pruebas del MVP

Servicio experimental: FARMEARLAB Turnos / TurnosWSP se utiliza actualmente para pruebas funcionales con consultorios, profesionales y pacientes ficticios. No representa la prestación de un servicio de salud.

1. Objeto

El servicio permite evaluar un flujo de solicitud, selección de profesionales, disponibilidad, reserva, confirmación, consulta y cancelación de turnos mediante WhatsApp.

2. Uso autorizado

Las pruebas se realizan únicamente con participantes autorizados y datos ficticios. No cargues información de pacientes reales ni datos clínicos sensibles. El servicio no debe utilizarse para emergencias, diagnósticos o solicitudes de atención inmediata.

3. Disponibilidad

Al tratarse de un desarrollo experimental, el servicio puede sufrir interrupciones, reinicios y cambios sin previo aviso. Las reservas de prueba no garantizan turnos médicos reales ni generan obligaciones de atención por parte de un consultorio.

4. Privacidad

El tratamiento de información se describe en la política de privacidad. Las solicitudes de eliminación pueden realizarse siguiendo las instrucciones correspondientes.

5. Contacto y actualizaciones

Para consultas sobre las pruebas escribí a vjed.vjed@gmail.com. Estas condiciones se actualizarán antes de habilitar el servicio comercial.
